# QENAWY v2 — نسخة تبهر اللاعبين

نفس الهوية (كحلي `#0a1628` + أزرق `#2563eb` + أبيض) بس هيكل جديد كليا.

## التشغيل
دبل كليك `index.html` أو:
```
python -m http.server 8902
```
`http://127.0.0.1:8902`

## الأقسام
هيرو بعدادات متحركة + شريط متحرك للبرامج / البرامج (6 كروت بالصور) / رحلة 4 خطوات / نتائج حقيقية + اعتمادات / آراء / أسئلة شائعة / حجز واتساب + تحقق رقم مصري / تواصل وفوتر

## التعديل بعد كده
- نص: `index.html` (غيّر `data-ar` و`data-en` معا)
- لون: `:root` في `assets/css/style.css`
- واتساب: `201019815737` في `index.html` + `assets/js/main.js`
- صورة: بدّل الملف في `assets/images/` بنفس الاسم

## الريسبونسف
1200 / 1024 / 768 — قائمة همبرجر + شبكات عمود + هيرو عمود + فورم عمود. قيس بـ F12 على 360/768/1024/1440.
